# Unit economics workbook

SKU and channel unit economics for a fictional CPG company (**Northline Consumer Products**): per-unit contribution, channel mix, and a 12-month launch ramp / payback.

**File to open:** `Northline_Unit_Economics.xlsx`

## What you will see

- SKU register: price, COGS, variable selling, slotting, annual volume
- Per-unit P&L bridge and contribution margin % with RAG vs target
- Channel view: Grocery / Club / eComm / Convenience mix and fees
- 12-month ramp on the launch SKU (NL-Probiotic Bar) with cumulative payback
- Dashboard one-pager for a category or innovation review

Yellow cells with blue font are inputs. Black font is formulas.

## How to use

1. Open `01_Assumptions` and edit yellow SKU economics (and optional price/COGS stress %).
2. Read per-unit contribution and annual $000s on `02_Unit_P&L`.
3. Adjust channel mix and fee % on `03_Channel_View`.
4. Stress volume and launch spend on `04_Cohort_or_Ramp` to see payback month.
5. Use `05_Dashboard` as the one-pager.

## Tabs

## Stack

Excel (formulas only — no VBA). Built so another analyst can inherit the file from the data dictionary.

## Not included on purpose

- Live POS or ERP pulls
- Confidential employer data
- Full P&L or three-statement model (this is *unit economics*, not the monthly book)

All sample numbers are fictional. Per-unit in **$**; annual flows in **$000s**.
